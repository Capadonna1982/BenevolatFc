1

Créer la base de données

Sur supabase.com — gratuit, pas de carte bancaire

  1. Crée un compte et un projet

    Va sur supabase.com → Start your project. Connecte-toi avec ton compte GitHub (le plus simple). Puis clique New project.

    app.supabase.com/new
    Créer un nouveau projet
    benevolat-fc
    •••••••••••• Generate
    East US (North Virginia) ⌄
    Create new project🖱️
    ⚠️
    Note le mot de passe de la base quelque part. Choisis une région proche de toi (ex. East US pour le Québec). La création prend ~2 minutes.

  2. Ouvre le « SQL Editor »

    Dans le menu de gauche, clique sur l'icône SQL Editor (symbole >_), puis + New query.

    app.supabase.com/project/…/sql
    benevolat-fc
    🏠 Home 🗂️ Table Editor >_ SQL Editor 🔐 Authentication ⚙️ Project Settings
    SQL Editor + New query
    query-1.sql▶ Run
    -- Colle le contenu de supabase/schema.sql ici
-- puis clique sur « Run »

  3. Colle le script schema.sql et lance-le

    Ouvre le fichier supabase/schema.sql du projet, copie tout son contenu, colle-le dans l'éditeur, puis clique Run (ou Ctrl/Cmd + Entrée).

    schema.sql — extrait▶ Run ✓
    -- Bénévolat FC : tables, sécurité (RLS), temps réel, données démo
create table activites   ( id …, nom text, heures numeric … );
create table evenements  ( id …, titre text, date date … );
create table besoins     ( … );   -- postes requis par événement
create table inscriptions( … );   -- choix des joueurs

alter table … enable row level security;
alter publication supabase_realtime add table inscriptions;
-- + insertion des données de démonstration…
    ✅
    Tu dois voir « Success. No rows returned ». Va dans Table Editor : les tables activites, evenements, besoins, inscriptions apparaissent avec les données de démo.
2

Brancher les clés dans l'app

Copier 2 valeurs publiques dans supabase/config.js

  1. Récupère l'URL et la clé « anon »

    Menu de gauche → Project Settings (⚙️) → onglet API. Tu vois deux infos à copier :

    app.supabase.com/project/…/settings/api
    benevolat-fc
    🏠 Home 🗂️ Table Editor >_ SQL Editor ⚙️ Settings › API
    Project API
    https://abcdefgh.supabase.co📋 Copy
    eyJhbGciOiJIUzI1NiIsInR5cCI…📋 Copy
    ⚠️ Ne copie PAS la clé « service_role » (secrète).

  2. Colle-les dans supabase/config.js

    Ouvre le fichier, remplis les 2 lignes surlignées (garde bien les guillemets). C'est tout ce qui change dans ce fichier.

    supabase/config.js
    /* Va sur Supabase → Settings → API pour ces 2 valeurs */
window.SUPABASE_URL      = "https://abcdefgh.supabase.co";  // ① Project URL
window.SUPABASE_ANON_KEY = "eyJhbGciOiJIUzI1Ni…";            // ② clé anon public

// Si ces 2 champs restent vides → mode démo hors-ligne (localStorage).
window.SUPA_ENABLED = !!(window.SUPABASE_URL && window.SUPABASE_ANON_KEY);
    🔒
    Ces 2 valeurs sont publiques par conception — la sécurité est assurée par les règles RLS du script SQL. Aucun secret n'est exposé.

  3. Pousse le changement sur GitHub

    Enregistre le fichier et envoie-le sur ton dépôt BenevolatFc. Depuis l'interface web de GitHub : ouvre supabase/config.js → ✏️ Edit → colle → Commit changes. (Ou dis-moi les 2 valeurs et je le fais pour toi.)

3

Déployer sur Vercel

Publier le site — aucune configuration nécessaire

  1. Connecte-toi et importe le dépôt

    Va sur vercel.com → connecte-toi avec GitHub. Clique Add New… → Project, puis Import à côté du dépôt BenevolatFc.

    vercel.com/new
    Import Git Repository
    📦 toncompte / BenevolatFcImport🖱️
    📦 toncompte / autre-depotImport

  2. Clique « Deploy »

    Ne touche à aucun réglage (le projet est un site statique). Clique simplement Deploy.

    vercel.com/new/…/configure
    Configure Project — BenevolatFc
    Other (aucun) — parfait ✓
    Laisser par défaut
    ▲ Deploy🖱️
    🎉
    Après ~30 secondes : « Congratulations! ». Tu obtiens une adresse du type benevolat-fc.vercel.app — c'est ton app en ligne, partageable avec toute l'équipe.

  3. À chaque futur changement

    Vercel redéploie automatiquement à chaque commit sur GitHub. Tu ne referas plus jamais cette étape.
